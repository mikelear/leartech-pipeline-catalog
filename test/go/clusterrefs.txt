# each reports a PR comment and reads ${CLUSTER_ID:-} in the same script that calls prpost.

#   (a) `. .jx/variables.sh` at the top of the report script (the file is on the workspace by
#       then), or
#   (b) `prpost` resolving the cluster from the file itself, so the flag and the shell
#       interpolation both disappear.
# (b) removes the whole class; it is the change this file exists to make visible.
#
# This list may only SHRINK. A file not listed here must not declare the keyRef (the check
# fails), and a line whose file no longer declares it must be deleted (the check fails) — the
# same ratchet as test/go/orphan_tools.txt, for the same reason: a guard nobody prunes stops
# describing the tree.
